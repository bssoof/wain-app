# Demo venue — pending asset pack

The demo venue currently borrows food and drink photographs from
`assets/images/demo_menu/`. **Those are not venue photos.** Until the shots
below are supplied, the demo is `READY_FOR_ASSET_PACK`, not customer-ready.

Drop the files into this directory using exactly these names, then flip
`demoVenueAssetPackInstalled` to `true` in
`lib/features/demo/data/demo_venue_catalog.dart`. No other code changes needed.

| # | File | Shot |
|---|------|------|
| 1 | `storefront.jpg` | Exterior / shopfront, daylight |
| 2 | `indoor_seating.jpg` | Indoor seating area, wide |
| 3 | `coffee_bar.jpg` | Espresso bar / barista station |
| 4 | `food_table.jpg` | Table set with food, overhead |
| 5 | `workspace.jpg` | Laptop-friendly corner |
| 6 | `outdoor_terrace.jpg` | Outdoor seating |

Requirements: 4:3 or 1:1, at least 1200px on the long edge, consistent
white balance, no readable third-party branding, no identifiable faces.

**Provenance rule:** these must be original photographs, or images the project
holds a licence for. Google Maps / Places imagery may not be copied here — it
requires the Google Places photo contract and its attribution, which this
directory does not carry.
