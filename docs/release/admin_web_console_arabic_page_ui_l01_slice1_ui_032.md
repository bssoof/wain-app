# UI-032 - تنفيذ الدفعة الأولى من التعريب المبسط

Date: 2026-04-17
Scope: عناوين التنقل، ملاحظات الصفحات العامة، الترجمة المشتركة، ورسائل النصوص التقنية الظاهرة في صفحات الإدارة.
Decision: تنفيذ الدفعة الأولى من UI-L01 كتغيير نصي محدود لا يمس المسارات أو الصلاحيات أو عقود القراءة والأوامر.

## ما تغيّر

- تم تبسيط عناوين مسارات الإدارة:
  - نظرة عامة
  - طلبات الشحن
  - سجل المحفظة
  - طلبات عكس العمليات
  - حالة النظام
  - الجهات
  - الصور والملفات
  - العروض
  - القصص
  - المراجعات
  - إعدادات التطبيق
- تم استبدال ألفاظ تقنية ظاهرة مثل استدعاء سحابي، قناة النقل، والحالة المتوقعة بألفاظ عربية أبسط.
- تم إخفاء أسماء الخدمات الداخلية عن الواجهة واستبدالها بعبارات مثل الخدمة المتصلة، اتصال مباشر بالخدمة، وقاعدة البيانات.
- تم تحديث نصوص النظرة العامة وحالات البيانات القديمة والصفحات المؤقتة أثناء التحميل.
- تم تنظيف نصوص العروض والقصص والمراجعات والإعدادات والصور والملفات من المصطلحات التقنية الظاهرة.

## ما لم يتغير

- لم تتغير أسماء المسارات.
- لم تتغير مفاتيح الصلاحيات.
- لم تتغير مفاتيح الأوامر أو حقول الطلبات.
- لم تتغير مصادر البيانات أو سلوك التحميل.
- لم تتغير معرفات الاختبارات الخاصة بالتدفقات.

## الخطوة التالية

الدفعة التالية من UI-L01 يجب أن تمسك صفحات المالية صفحة صفحة:

1. النظرة العامة.
2. طلبات الشحن.
3. سجل المحفظة.
4. طلبات عكس العمليات.
5. حالة النظام.

هدف الدفعة التالية ليس تغيير العقود، بل ترتيب النصوص داخل كل صفحة وتقليل ازدحام الأفعال والجداول.
