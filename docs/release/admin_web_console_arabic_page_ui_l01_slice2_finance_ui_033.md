# UI-033 - تنفيذ دفعة صفحات المالية من التعريب المبسط

Date: 2026-04-17
Scope: صفحات المالية في لوحة الإدارة: النظرة العامة، طلبات الشحن، سجل المحفظة، تصحيح العمليات، وحالة النظام.
Decision: تنفيذ دفعة UI-L01 الثانية كتغيير نصي وتنظيمي محدود لا يغيّر المسارات أو الصلاحيات أو عقود القراءة والأوامر.

## السبب

بعد الدفعة الأولى من UI-L01 بقيت صفحات المالية تحتوي ألفاظًا رسمية أو تقنية مثل طابور الشحن، قيود دفتر المحفظة، العكس، الجاهزية، والأمر. هذه الألفاظ صحيحة تقنيًا لكنها أقل وضوحًا لمستخدم إداري غير تقني.

## ما تغيّر

- تم تبسيط صفحة طلبات الشحن:
  - طابور الشحن المعلق أصبح طلبات الشحن التي تنتظر القرار.
  - أعمدة الجدول أصبحت أوضح: رقم الطلب، صاحب الطلب، تاريخ الطلب، القرار.
  - رسالة دور القراءة فقط أصبحت مباشرة وتشرح سبب غياب قرارات القبول والرفض.
- تم تبسيط صفحة سجل المحفظة:
  - قيود دفتر المحفظة أصبحت سجل عمليات المحفظة.
  - العكس أصبح تصحيح العملية.
  - إجراء إنشاء العكس أصبح طلب تصحيح.
  - نتائج التصحيح أصبحت تستخدم لغة اعتماد وتصحيح بدل لغة دفترية.
- تم تبسيط صفحة حالة النظام:
  - تقرير جاهزية المحفظة أصبح ملخص حالة المحفظة.
  - فحوصات الجاهزية أصبحت فحوصات النظام.
  - تشغيل فحص الجاهزية أصبح تحديث حالة النظام.
- تم تبسيط صفحة اعتماد التصحيح:
  - اعتماد العكس أصبح اعتماد التصحيح.
  - معرّف طلب العكس أصبح رقم طلب التصحيح.
  - أزيل placeholder إنجليزي ظاهر من حقل الإدخال.
- تم تحديث رسائل التحميل في النظرة العامة حتى لا تعرض ألفاظ الطابور أو الجاهزية.
- تم تحديث ترجمة الصلاحيات المشتركة المرتبطة بطلب التصحيح واعتماده.

## ما لم يتغير

- لم تتغير مفاتيح الأوامر الداخلية.
- لم تتغير payload fields أو أسماء callables.
- لم تتغير RBAC أو visibility policy.
- لم تتغير loaders أو مصادر البيانات.
- لم تتغير معرفات الاختبارات اللازمة لتدفقات الأوامر.

## التحقق

- مرّت الاختبارات الموجهة:
  - `components/dashboard/operational-dashboard-shell.test.tsx`
  - `components/finance/finance-surfaces.test.tsx`
  - `components/finance/finance-read-states.test.tsx`
  - `lib/finance/surface-affordances.test.ts`
  - `lib/admin/admin-localization.test.ts`
- النتيجة: 5 ملفات، 29 اختبارًا ناجحًا.
- مرّ فحص الأنواع: `npx tsc --noEmit --pretty false`.
- مرّ بناء الإنتاج: `npm run build`.
- تم تشغيل localhost من جديد بعد البناء.
- تحقق المتصفح على `/admin/dashboard`:
  - HTTP 200.
  - لا يوجد Next error overlay.
  - لا توجد console errors.
- تحققت مسارات المالية عبر HTTP 200 بدون Server Error:
  - `/admin/topups`
  - `/admin/wallet-audit`
  - `/admin/reversals`
  - `/admin/readiness`

## ملاحظة تشغيلية

تم تأكيد أن خطأ `__webpack_modules__[moduleId] is not a function` كان ناتجًا عن حالة كاش محلية في `.next` بعد تشغيل build أثناء عمل dev server. تم إيقاف dev server، تنظيف الحالة، ثم البناء وإعادة تشغيل localhost بدون رجوع الخطأ.

## الخطوة التالية

متابعة UI-L01 صفحة صفحة خارج المالية، والأولوية المنطقية التالية هي صفحة الجهات لأنها أكبر سطح جدولي تشغيلي بعد المالية.
