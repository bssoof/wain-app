## Methodology

Each route has a triage block. Reviewer fills in:
- **P0** — visual issues blocking core admin work
- **P1** — issues hurting scan-ability or hierarchy
- **P2** — polish items, low-impact
- **Action items** — concrete fixes for the master plan phases

Categories to consider while reviewing:
- Visual hierarchy (what stands out, what gets lost)
- Density (too crowded vs wasteful empty space)
- Color usage (semantic vs decorative)
- Typography (sizes, weights, alignment)
- Iconography (missing or text-only buttons)
- States (loading/empty/error visibility)
- Action affordances (clarity of what the user can do)
- Mobile readiness (visible breakage hints at this viewport)
