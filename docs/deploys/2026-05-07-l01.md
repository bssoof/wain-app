## Note on Partner Configs
If existing partner records lack `allowedSchemes`/`allowedHosts` or their snake_case equivalents, the code falls back to a migration allowlist for known transport partner HTTPS hosts. Ops should populate explicit allowlist fields on each partner record before removing the fallback.
